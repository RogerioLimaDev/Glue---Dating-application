# O Conceito

**Glue** é uma aplicação de dating onde o compromisso importa mais do que a quantidade de matches.

Tagline:

> A dating application where commitment matters.

A proposta central:

> We don't match people. We match commitments.

Glue não tenta substituir completamente os aplicativos de relacionamento. Ele muda o ponto de partida: em vez de começar com uma conversa sem prazo, começa com um compromisso mútuo de encontro, com regras e expectativas explícitas.

## O que torna o Glue diferente

- **Compromisso antes da conversa longa:** os participantes concordam com um encontro antes de investir semanas em mensagens.
- **Expectativas alinhadas:** local, horário, tipo de programa e stakes são visíveis desde o início.
- **Consequência para ghosting:** quando ambos depositam algo de valor, faltar sem justificativa tem um custo claro.
- **Verificação no mundo físico:** o Date Code cria uma ponte entre o evento real e o registro digital.
- **Separação de dados privados:** perfis, fotos e mensagens permanecem off-chain.

## O Vow

Um **Vow** é a unidade central do protocolo. Ele não é dinheiro, não é pagamento e não é ingresso.

> A Vow isn't a payment. It's the value of commitment made tangible.

- Cada participante deposita a mesma quantidade de Vows para formar um compromisso.
- Os Vows ficam bloqueados enquanto o compromisso está ativo.
- Após a verificação do encontro, o protocolo liquida o compromisso conforme as regras definidas.

## Visão de curto prazo

Para o MVP, Glue demonstra um fluxo completo de ponta a ponta: descobrir alguém, fazer um Vow, bloquear tokens, combinar o encontro, verificar com Date Code e liquidar o compromisso.

## Visão de longo prazo

O Vow Protocol pode ser aplicado a outros tipos de compromisso além de encontros. O dating é a primeira aplicação, mas a camada de regras é genérica o suficiente para ser reaproveitada.

## Decisões em aberto

- O Vow deve ser fungível ou específico por compromisso?
- Deve existir uma tabela de preços para Vows ou eles são adquiridos por demanda?
- O aplicativo deve ter um modelo de assinatura além da compra de Vows?
